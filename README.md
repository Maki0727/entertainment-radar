# ENTERTAINMENT RADAR 公開テスト版

漫画・ライトノベルの出版社公式新刊カレンダーから2026-10-12に手動確認した12件を掲載した静的サイトです。出典は各カードから辿れます。架空データは削除済み。現在は自動更新ではありません。ゲーム・アニメ・VTuberはまだ未収録です。

## 使い方
- index.html を Chrome で開く。検索、今日/7日間、ジャンル切替など利用可能。
- 日付と作品情報を更新するときは events.js の window.RADAR_EVENTS を編集する。出版元の一次情報を確認し、verifiedとサイト内の最終確認日時も更新する。
- 日時は JST として扱います。

## 無料で一般公開 (Cloudflare Pages)
1. https://dash.cloudflare.com/ にログイン。
2. Workers & Pages > Create > Pages > Drag and drop / Upload assets を選択。
3. この ZIP をそのままアップロードする（または展開した中のファイル一式）。
4. サイト名を決めて Deploy。表示された `*.pages.dev` URL を他の人へ共有する。
5. データを更新したときは修正版を再アップロードして再デプロイする。

注意：ドラッグ&ドロップ方式で始めると、そのプロジェクトを後から Git 連携方式へ切り替えることはできません。自動更新前提で始めたい場合、最初から GitHub 連携で Pages プロジェクトを作ってください。

## まだ必要なこと
- 定期更新（GitHub Actions / Workers）と公式フィード取得
- ゲーム・アニメ・VTuberの確実な公式情報源の追加
- 運営者情報、問い合わせ方法、プライバシーポリシー（広告導入する場合）
- 公式ページの発売日変更の検知

実運用上の注意：現状は初期データ12件だけなので、時間とともに古くなります。常時新着が自動で増えるサイトではありません。
